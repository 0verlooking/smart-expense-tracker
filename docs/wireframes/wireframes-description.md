# Wireframes - Smart Expense Tracker

## Опис інтерфейсу користувача

### 1. Загальна структура

Всі сторінки мають єдину структуру:
- **AppBar** (верхня панель) з назвою додатку
- **Drawer** (бокова панель) з навігаційним меню
- **Main Content Area** (основна область контенту)
- **Floating Action Button** (плаваюча кнопка) для швидкого додавання витрат

### 7. Кольорова схема

- **Primary Color:** #1976d2 (синій)
- **Secondary Color:** #dc004e (червоний)
- **Background:** #f5f5f5 (світло-сірий)
- **Text:** #212121 (темно-сірий)
- **Success:** #4caf50 (зелений)
- **Warning:** #ff9800 (помаранчевий)

### 8. Типографія

- **Заголовки (h4):** 2.125rem
- **Підзаголовки (h6):** 1.25rem
- **Body Text:** 1rem
- **Button Text:** 0.875rem

### 9. Респонсивність

- **Mobile (< 600px):** Одноколонковий макет
- **Tablet (600-960px):** Двоколонковий макет
- **Desktop (> 960px):** Багатоколонковий макет

### 10. Інтерактивні елементи

- **Hover effects** на кнопках та картках
- **Smooth transitions** при відкритті діалогів
- **Loading indicators** під час завантаження даних
- **Snackbar notifications** для повідомлень користувачу
- **Confirmation dialogs** перед видаленням даних
